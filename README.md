# HardwareInfo

Planned hardware inventory library with a C ABI for Windows applications.

**Status: planned; no implementation published.** This repository does not yet provide library source, a C header, build instructions, or release binaries. Hardware coverage and architecture support are unverified.

The initial milestone is a small read-only inventory API with explicit ownership/error conventions, a consumer example, and Windows validation. Broader CPU, GPU, memory, disk, monitor, network, and battery coverage is a goal, not an available feature list.
